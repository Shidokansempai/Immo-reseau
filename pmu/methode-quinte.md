# Méthode Quinté+ — grille de notation (v2)

Grille corrigée après le Quinté du 07/11/2026 (Deauville, PSF 1 900 m).
Chaque partant reçoit des points ; on joue les 6 à 8 meilleurs scores.

| Critère | Points |
|---|---|
| Gagné ou placé sur le même parcours (même piste + distance) depuis moins de 30 jours | +3 |
| Placé (top 5) dans la course de référence directe | +2 |
| Spécialiste du parcours (cité par la presse) | +1 |
| Corde basse (≤ 8) sur PSF | +1 |
| Corde très haute (≥ 14) | −1 |
| Poids léger (≤ 54,5 kg) en handicap | +1 |
| Poids lourd (≥ 58 kg) sans classe prouvée | −1 |
| Jockey en forme, ou retrouve le jockey d'une victoire | +1 |
| Victoire récente ailleurs (< 60 jours) | +1 |
| Excuse de mauvaise course (corde, distance, poids) | +1 max |
| Retour après plus de 90 jours d'absence | −2 |

Le consensus presse sert seulement à choisir la base (gagnant), pas les places.

## Leçons
- Ne pas surpondérer un « rebond » sur simple excuse de corde (Al Max 4 : non placé).
- Les vainqueurs récents sur le parcours exact, en bas du handicap, sont prioritaires
  (Her Christopher 2ᵉ, Hermes Wood 4ᵉ).
- Un outsider à corde basse qui retrouve son jockey gagnant doit rester dans le champ
  (East Grey 3ᵉ à 21/1).
